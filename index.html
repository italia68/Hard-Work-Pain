THE GRIND LOG

Every update to Platemate, from the very first commit to today. No spin, no marketing fluff — just what actually shipped and when.

v1.3 July 29, 2026
Nutrition Tracking Arrives
  • New Food tab — log calories, protein, carbs & fat for every day
  • Food search across a built-in common-foods library, the USDA FoodData Central database, and Open Food Facts for packaged items
  • Set daily calorie & macro goals and watch progress bars fill in
  • Log food straight from the main + button on Today, alongside lifts and cardio
  • Fixed a bug where per-set weights weren't actually saving when editing a logged exercise
v1.2 July 28, 2026
Shared Templates, Reimagined
  • Renamed Community → Shared Templates
  • Search and muscle-group filters when browsing Shared Templates
  • Like templates you find useful
  • Add Cardio activities directly inside a template, not just strength exercises
  • Fixed weight not saving correctly when editing exercises inside a template
  • Templates now show who created them
  • Cleaner spacing and layout on template cards
— Mid-Late July 2026
Growth, SEO & an Admin Dashboard
  • Converted the blog to real static pages — each post got its own crawlable URL, title, and meta description
  • Added a repeatable build script so new blog posts take one command instead of hand-built pages
  • Added Organization, WebSite, and FAQ structured data to help the site actually surface in search
  • Built an admin dashboard: total users, workout/cardio/template counts, a searchable user table
  • User profiles now track signup date and last login
  • Fixed a silent Firestore security rule bug that was affecting Shared Templates
— Late June 2026
Hard Work & Pain Launches
  • Built this website — Home, About, Blog, Platemate, and Contact — to give Platemate a real home
  • Migrated Platemate from Netlify to GitHub Pages for reliable, free hosting
  • Unified History — lifting and cardio sessions now show together in one chronological timeline
  • Replaced the old PRs tab with a full Analytics dashboard: streaks, volume trends, a 30-day heatmap, and auto-tracked personal records
v1.0 – v1.1 Mid-June 2026
The Big Rebuild
  • Rebuilt logging around a real set-by-set system — every set gets its own weight and reps, not just one number per exercise
  • Full-screen exercise picker with muscle-group filters, replacing a plain text field
  • Visual dumbbell and barbell plate-loading calculators
  • Templates arrive — save a routine once, reuse it forever, with early community sharing
  • Added every Les Mills class and 20+ other cardio activities
  • Versioned "what's new" splash screen so updates don't go unnoticed
  • Forgot-password flow and toast notifications replacing plain browser alerts
v0.1 June 2026
Day One
  • Platemate is born — a simple exercise and cardio logger, no fluff, built to solve one problem: losing track of your lifts
  • Firebase Auth and Firestore added so data is never tied to a single browser again
  • Multi-set support for machine exercises where weight changes set to set
